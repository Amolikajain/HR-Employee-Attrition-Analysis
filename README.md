# HR Employee Attrition Analysis Dashboard

An interactive Excel-based HR analytics project focused on analyzing employee
attrition and identifying patterns across different employee attributes.

## 📊 Project Overview

This project analyzes employee data to understand attrition patterns and
explore the factors associated with employee turnover.

The dashboard provides a visual and interactive way to analyze employee
attrition across different departments, job roles, demographics, and
employment-related factors.

## 🛠️ Tools & Techniques

- Microsoft Excel
- PivotTables
- PivotCharts
- Slicers
- KPI Analysis
- Data Visualization
- Excel-based Data Analysis

## 📈 Key Analysis

The project analyzes employee attrition across factors such as:

- Department
- Job Role
- Age Group
- Gender
- Education
- Job Satisfaction
- Monthly Income
- Years at Company
- Overtime
- Work Experience

## 🎯 Dashboard Features

- Employee attrition KPIs
- Interactive PivotTables
- PivotCharts
- Slicers for dynamic filtering
- Department-wise attrition analysis
- Job role-wise analysis
- Employee demographic analysis
- Comparison of attrition across different employee attributes

## 💡 Key Objectives

The main objectives of this project are to:

- Understand overall employee attrition patterns
- Identify employee groups with higher attrition
- Compare attrition across departments and job roles
- Analyze factors associated with employee turnover
- Present HR insights through interactive visualizations
